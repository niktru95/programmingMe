# ⚡ Программируй на JS

Веб-ресурс для практики JavaScript: выбирайте тему и решайте задачи прямо в браузере.

**9 тем × 30 задач = 270 задач.** Порядок задач в каждой теме — случайный, а тестовые данные многих задач генерируются заново при каждой загрузке страницы.

## Темы

| Тема | Что тренирует |
| --- | --- |
| 🔢 Основы | переменные, типы, арифметика, преобразования |
| 🔀 Условия и циклы | if/else, for/while, FizzBuzz, простые числа |
| 🔤 Строки | реверс, палиндромы, camelCase/snake_case |
| 📚 Массивы | суммы, максимумы, сдвиги, чанкинг |
| ⚙️ Методы массивов | map, filter, reduce, flat |
| 📦 Объекты | слияние, группировка, массивы объектов |
| 🧠 Функции и замыкания | счётчики, каррирование, композиция |
| ⏱️ Асинхронность | Promise, async/await, race/all |
| 🔡 Методы строк | toUpperCase, indexOf, slice, split/join, padStart, replace, trim |

## Возможности

- 📝 Встроенный редактор кода и кнопка «Выполнить» — решение проверяется тестами
- 🎲 Случайный порядок задач и кнопка «Перемешать»
- 💡 Подсказки (по одной, с пометкой «решена с подсказкой»)
- 📖 Авторское решение с пояснением
- 💾 Прогресс и черновики кода сохраняются в localStorage браузера
- 🔒 Код пользователя выполняется в песочнице (sandbox-iframe) и не может навредить странице
- 📱 Адаптивная вёрстка, работает с телефона

## Как запустить локально

Просто откройте `index.html` в любом современном браузере — никакой сборки и серверов не нужно.

Или через VS Code: установите расширение **Live Server**, кликните правой кнопкой по `index.html` → **Open with Live Server**.

## Деплой на GitHub Pages

1. Запушьте репозиторий на GitHub (ветка `main`).
2. Откройте репозиторий → **Settings** → **Pages**.
3. В блоке **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, Folder — **/ (root)**, кнопка **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ник>.github.io/programmingMe/`.

## Как добавить свои задачи

Все задачи лежат в `js/data/` — по одному файлу на тему (`t01-basics.js`, ..., `t09-string-methods.js`).

Пример задачи:

```js
{ id: 'my-01', title: 'Название', difficulty: 1,            // 1 — легко, 2 — средне, 3 — сложно
  description: 'Условие задачи.\n\nПример:\nmyFunc(2) → 4',
  functionName: 'myFunc',
  starterCode: 'function myFunc(n) {\n  // ваш код\n}',
  hints: ['Подсказка 1', 'Подсказка 2'],
  tests: [
    { input: [2], expected: 4 },
    { input: [0], expected: 0 }
  ],
  solution: 'function myFunc(n) {\n  return n * 2;\n}' }
```

### Форматы тестов

- **Обычный вызов:** `{ input: [аргументы...], expected: результат }`
- **Цепочка вызовов** (для замыканий): `{ steps: [[арг], [арг]], expected: результат }` — вызовется `fn(арг)(арг)`
- **Проверочная функция:** `{ run: '(fn) => fn([1, 2]).then(v => v)', expected: [1, 2] }`
- **Случайные данные:** вместо `tests` укажите `gen: function () { return [тесты...]; }` — данные будут генерироваться при каждой загрузке страницы.

## Автотесты

Откройте `index.html?selftest` — в заголовке вкладки появится `SELFTEST-OK` или `SELFTEST-FAIL: <что сломалось>`.
